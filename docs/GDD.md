# Quiet Acres — 게임 기획 문서 (GDD)

## 1. 한 줄 컨셉
버려진 시골 농장을 물려받은 주인공이, 하루하루 농사를 짓고 마을 사람들과 관계를 쌓으며 자신만의 속도로 정착해가는 2D 탑다운 농장 시뮬레이션.

## 2. 레퍼런스
- Stardew Valley — 농사/관계/시즌 루프의 기본 골격
- Animal Crossing — 느긋한 텐션, 수집·꾸미기 요소
- My Time at Portia — 제작/퀘스트 결합 방식 (참고만, 범위는 축소)

## 3. 디자인 원칙 (Design Pillars)
1. **느림이 미덕** — 타이머에 쫓기지 않는다. 실패해도 손해가 크지 않게 설계.
2. **짧은 하루, 쌓이는 장기 목표** — 하루 루프는 5~10분, 그 위에 시즌/연 단위 성장이 쌓인다.
3. **선택은 있지만 강요하지 않는다** — 농사/채집/관계 중 뭘 우선해도 진행 가능.

## 4. 핵심 루프 (Core Loop)
```
기상 → (오늘 할 일 확인) → 농장일(밭갈기/씨뿌리기/물주기/수확)
     → 마을 나가기(채집/판매/대화) → 저녁에 귀가 → 취침 → 다음 날
```
- 하루는 인게임 시간으로 흐르고, 자정이 되면 강제로 하루가 넘어감(패널티 없음, 다음날 살짝 피로 정도).
- 매 하루 루프가 반복되지만, 계절이 바뀌며 작물·이벤트·마을 분위기가 달라짐 → 반복 속 변주.

## 5. 시스템 목록 (전체 비전 — 전부 MVP는 아님)
| 시스템 | 설명 | MVP 포함 |
|---|---|---|
| 이동/카메라 | 탑다운 이동, 부드러운 추적 카메라 | ✅ |
| 농지 시스템 | 타일 갈기 → 씨뿌리기 → 물주기 → 성장 → 수확 | ✅ (작물 1종) |
| 낮/밤 & 시간 | 시간 진행, 하루 전환 | ✅ (단순 버전) |
| 인벤토리 | 아이템 소지, 씨앗/작물 슬롯 | ✅ (기본형) |
| 판매/경제 | 수확물을 팔아 씨앗·도구 구매 | ▶ 2단계 |
| 마을 NPC & 호감도 | 대화, 선물, 관계 성장 | ▶ 2단계 |
| 시즌 전환 | 봄/여름/가을/겨울, 작물 변화 | ▶ 3단계 |
| 집 꾸미기/업그레이드 | 가구, 농장 확장 | ▶ 3단계 |
| 저장/불러오기 | 세이브 시스템 | ▶ 2단계 (MVP 이후 바로) |

## 6. MVP 범위 (지금 만드는 것)
플레이 가능한 최소 단위: **"밭을 갈고, 씨를 심고, 물을 주고, 자라서 수확한다"** 루프가 실제로 돌아가는 것.

- 플레이어 상하좌우 이동 (8방향 아님, 4방향으로 단순화)
- 5x5 농장 타일 그리드, 각 타일은 `잔디 → 갈아엎음 → 심음 → 성장중 → 수확가능` 상태를 가짐
- 상호작용 키 하나로: 갈기 / 심기 / 물주기 / 수확 (상태에 따라 자동으로 알맞은 동작 수행)
- 인게임 시간이 흘러 작물이 단계별로 자람 (일정 시간마다 성장 단계 +1)
- 수확 시 인벤토리(딕셔너리 형태)에 작물 개수 누적, 화면 좌상단에 텍스트로 표시

이번 마일스톤에는 그래픽 에셋이 없으므로 색깔 사각형(ColorRect)으로 모든 것을 표현한다. 비주얼은 나중에 교체.

## 7. 조작
- 이동: W/A/S/D 또는 방향키
- 상호작용: E 또는 스페이스

## 8. 로드맵
1. **M0 — 스캐폴드** (지금): 프로젝트 구조, 플레이어 이동, 농장 타일 프로토타입
2. **M1**: 인벤토리 UI, 씨앗 여러 종류, 판매/구매(상점 NPC 1명)
3. **M2**: 세이브/로드, 하루 전환 시 피로/스태미나
4. **M3**: 마을 NPC 1~2명 + 대화 시스템
5. **M4**: 시즌 전환, 계절별 작물
6. **M5**: 비주얼 교체(픽셀 아트), 사운드, 폴리싱
