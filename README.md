# Quiet Acres

느긋한 농장/마을 생활 시뮬레이션 게임. Godot 4 (GDScript)로 제작.

## 기획
전체 기획은 [docs/GDD.md](docs/GDD.md) 참고.

## 실행 방법
1. [Godot 4.x](https://godotengine.org/download) 설치
2. Godot 실행 → "Import" → 이 저장소의 `project.godot` 선택
3. F5 또는 재생 버튼으로 실행

## 조작
- 이동: 방향키 또는 WASD
- 상호작용(밭갈기/심기/물주기/수확): Space 또는 Enter

## 현재 상태 (M0 — 스캐폴드)
- 플레이어 이동
- 5x5 농장 타일: 갈기 → 심기 → 물주기 → 성장 → 수확 루프 프로토타입 (에셋 없이 색상 사각형으로 표현)
- 인벤토리/시간 HUD 표시

로드맵은 GDD의 9번 항목 참고.
