# Quiet Acres

버려진 시골 농장을 물려받은 주인공이, 서두르지 않고 자신만의 속도로 다시 뿌리내리는 2D 탑다운 농장 생활 시뮬레이션. Godot 4 (GDScript)로 제작.

## 방향성
- **느림이 미덕.** 타이머에 쫓기지 않고, 실패해도 손해가 크지 않다. 하루 루프는 5~10분이지만 그 위에 계절·연 단위로 천천히 쌓이는 장기 목표가 있다 — Stardew Valley의 루프에 Animal Crossing의 느긋한 텐션을 섞되, 범위는 훨씬 작게 잡는다.
- **차별점은 사람이 아니라 작은 생명들.** 지금까지 가장 공들인 부분은 사실 NPC가 아니라 chomp 마스코트 3마리와 장식용 동물(양/닭)이다. 각자 성격이 다르게 튜닝된 배회 AI로 움직이고, 서로 겹치지 않게 피하고, 끼리끼리 무리 짓기도 하고, 플레이어를 졸졸 따라다니지 않고 자기 삶을 사는 것처럼 보인다. "농장에 진짜 뭔가가 살아있다"는 느낌이 이 게임의 핵심 훅이 될 수 있다고 보고 있다.
- **다음 콘텐츠 축은 관계.** 지금은 마을 NPC(미나/테오)와 대화만 순환될 뿐, 관계가 쌓인다는 느낌이 없다. 선물·호감도 시스템이 자연스러운 다음 단계 — 그 다음은 사운드, 집/농장 꾸미기 확장 순으로 이어갈 예정.

## 기획
전체 기획은 [docs/GDD.md](docs/GDD.md) 참고.

## 실행 방법
1. [Godot 4.x](https://godotengine.org/download) 설치
2. Godot 실행 → "Import" → 이 저장소의 `project.godot` 선택
3. F5 또는 재생 버튼으로 실행

## 조작
- 이동: 방향키 또는 WASD
- 상호작용(밭갈기/심기/물주기/수확, NPC 대화): Space 또는 Enter
- 숫자키(1/2/3/4): 심을 씨앗 선택 (상점 UI가 열려 있을 때는 해당 씨앗 구매)
- 상점 UI가 열려 있을 때: X = 보유 작물 전부 판매, ESC = 상점 닫기
- 대화창이 열려 있을 때: ESC = 닫기 (다시 상호작용하면 다음 대사로 이어짐)
- K = 수동 저장, L = 수동 불러오기 (하루가 바뀔 때는 자동 저장됨)

## 현재 상태 (M5 — 폴리싱 + 첫 에셋 적용, MVP 로드맵 마지막 단계)
- 플레이어 이동, 농장 타일 갈기 → 심기 → 물주기 → 성장 → 수확 루프
- 씨앗 4종(순무/당근/감자/배추), 종류별 성장 시간·판매가·재배 가능 계절 차등
- 골드 시스템 + 상점 NPC(씨앗 구매 / 작물 전체 판매, 계절별 재배 가능 시기 표시)
- 스태미나 시스템: 밭일 행동마다 소모, 다 떨어지면 행동 불가, 하루가 바뀌면 회복
- 세이브/로드: `user://savegame.json`에 저장, 하루 전환 시 자동 저장 + K/L 수동 저장·불러오기
- 마을 NPC 2명(미나/테오) + 대화 시스템: 상호작용할 때마다 대사가 순서대로 이어짐
- 계절 시스템: 봄→여름→가을→겨울 (계절당 인게임 7일), 계절이 맞지 않는 씨앗은 심을 수 없음
- **폴리싱(코드):** 계절 전환 시 배경색이 부드럽게 트윈, 밭일 성공 시 타일이 살짝 커졌다 줄어드는 펄스, 이동 중 캐릭터가 살짝 위아래로 흔들리는 걷기 애니메이션, NPC들의 은은한 대기 bob 애니메이션, HUD 텍스트 뒤 반투명 패널로 가독성 개선
- HUD에 날짜/계절/연차, 골드, 스태미나, 선택된 씨앗, 씨앗/작물 인벤토리 텍스트 표시

### 에셋 적용 (Kenney "Tiny Farm" 타일셋 + chomp 마스코트)
- `assets/tileset/tilemap_packed.png` (Kenney, CC0): 밭 타일의 갈아엎은 흙/심은 씨앗/자라는 중/수확 가능 단계를 실제 스프라이트로 표시(잔디 상태는 색상 유지)
- 미나는 타일셋의 농부 초상 스프라이트 그대로 사용
- **상점(ShopNPC)은 사람 초상 대신 헛간 건물 이미지로 교체함.** 타일셋에 X자 나무틀 벽+문/창문으로 된 3x4 타일짜리 헛간 벽면 조각이 있어서(`assets/tileset/shop_building.png`로 합성) 상점을 "말 거는 사람"이 아니라 "들어가는 건물"처럼 보이게 함. 옆에 있던 초록 뾰족 지붕 조각은 색感이 안 맞아서(잔디/덤불 계열) 같이 안 씀. 건물이라 다른 NPC들과 달리 위아래로 흔들리는 대기 애니메이션(bob)은 껐음(`ShopNPC.tscn`의 `bob_enabled = false`)
- **테오·플레이어는 새로 만든 전용 스프라이트 없이는 타일셋에 맞는 게 없어서**, 같은 농부 초상을 색조만 다르게 바꿔서(`assets/tileset/theo_portrait.png` 가죽/갈색톤, `assets/tileset/player_portrait.png` 초록톤) 각각 다른 캐릭터로 보이게 만듦. 완전히 새로 그린 그림이 아니라 기존 타일 색만 코드로 재가공한 것 — 진짜 오리지널 아트가 필요하면 별도 이미지 생성/에셋이 있어야 함
- `assets/chomp/chomp_idle.png`: 농장 마스코트 펫. 같은 방식으로 색조만 바꿔서 파랑(`chomp_idle_blue.png`)·핑크(`chomp_idle_pink.png`) 두 마리를 추가해 총 3마리. 평소엔 각자 제자리 근처를 혼자 어슬렁거리다가(WANDER) 플레이어가 일정 거리(기본 170px)보다 멀어지면 그제서야 쫓아와서(FOLLOW) 다시 가까워지면 어슬렁거리기로 돌아감 — 항상 붙어 따라다니지 않고 각자 노는 것처럼 보이게 하려는 의도 (`pet_chomp.gd`)
- 장식용 동물(양/닭)을 농장 근처에 배치 — 상호작용하면 울음소리 텍스트만 나오는 순수 플레이버, 게임 시스템에는 영향 없음. chomp처럼 제자리 근처를 어슬렁거리지만(공통 `Wanderer` 로직) 플레이어를 쫓아오지는 않음. 양은 느긋하게 오래 멈춰있고, 닭은 짧고 자주 종종거리는 식으로 서로 다르게 튜닝됨
- **주의:** `scripts/crop_data.gd`의 `sprite_coord`(작물별 수확 스프라이트 위치)는 타일셋에 정확히 일치하는 작물이 없어서(특히 순무/배추) 가장 비슷한 칸을 골라 추정한 값. Godot 에디터에서 실제로 보고 이상하면 그 좌표(`[col, row]`)만 바꾸면 됨
- 사운드는 아직 미적용

### 밭 갈았을 때(TILLED) 흙 스프라이트가 이웃과 이어져 보이도록 개선
- 처음엔 기존 타일셋의 흙 조각 3종(캡/중간/독립) + 회전으로 구현했는데, 코너·T자 연결부에서 이음새가 보이는 문제가 있어서 **`assets/tileset/tilled_dirt_synth.png`(직접 합성한 16조각 스프라이트시트, 4x4)로 교체함**. 좌/우/위/아래 이웃이 갈려있는지(4비트, 16가지 조합) 하나하나에 맞는 조각을 미리 만들어뒀기 때문에 회전 없이 조합 그대로 좌표를 찾아 쓰면 코너·T자·십자 전부 이음새 없이 이어짐(`CropData.get_tilled_dirt_coord()` + `farm_plot.gd`의 `_update_tilled_dirt_sprite`)
- `tilled_dirt_synth.png`는 PIL로 절차적으로 그린 것(둥근 사각형 + 점박이 텍스처): 기존 손그림 타일과 톤은 맞췄지만 진짜 오리지널 픽셀아트는 아님. 대각선 이웃까지 고려한 "안쪽 홈 파기"(47종 블롭 타일링)는 데모까지만 만들어보고 아직 적용 안 함 — 나중에 다시 다듬을 예정
- `main.gd`의 `_build_farm_grid()`가 그리드 생성 직후 각 `FarmPlot`에 `set_neighbors()`로 상하좌우 참조를 심어줌. 밭을 새로 갈 때(GRASS→TILLED) 이웃한 밭들에게 알려서 자기 스프라이트를 다시 계산하게 함(`_notify_neighbors_of_till`). 세이브 불러올 때도 순서대로 복원하다 보면 아직 로드 안 된 이웃 때문에 순간적으로 틀리게 그려질 수 있어서, 전부 로드한 뒤 한 번 더 전체 재계산하는 패스를 `game_manager.load_game()` 끝에 추가함

### 움직임 자연스러움 보정 (`scripts/wanderer.gd`)
- 대기 애니메이션(bob) 위상이 개체마다 랜덤하게 어긋나도록 한 것이 `Wanderer` 하위 클래스(펫/양/닭)에는 적용되지 않던 버그를 수정 — `Wanderer._ready()`가 `Interactable._ready()`(bob 초기화)를 호출하지 않고 있었음
- 목표 지점까지 즉시 최고 속도로 움직였다 뚝 멈추는 대신, 실제 속도가 목표 속도를 부드럽게 따라가도록(`_velocity` lerp) 해서 가속/감속이 있는 자연스러운 움직임으로 변경
- 새 배회 목표를 완전 무작위가 아니라 직전 이동 방향 근처(관성)로 우선 선택하도록 변경 — 갑자기 방향을 홱 트는 느낌을 줄임
- 좌우로 움직일 때 스프라이트가 이동 방향을 보도록 좌우 반전(`flip_h`) 추가
- **무리짓기(flocking):** 같은 `flock_group` 문자열을 가진 개체끼리만 서로를 인식해서 alignment(주변 평균 이동 방향으로 맞춤)+cohesion(주변 평균 위치로 약하게 끌림)을 적용. 양이 닭을 따라가는 등 이상한 조합을 막기 위해 종류별로 다른 그룹명을 사용(`chomp`/`sheep`/`chicken`). chomp 3마리는 어슬렁거릴 때(WANDER)만 무리를 이루고, 플레이어를 쫓아갈 때(FOLLOW)는 적용 안 됨. 양/닭은 현재 각각 1마리뿐이라 이웃이 없어 당장은 티가 안 나지만, 나중에 개체를 늘리면 바로 동작함
