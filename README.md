# Quiet Acres

느긋한 농장/마을 생활 시뮬레이션 게임. Godot 4 (GDScript)로 제작.

## 기획
전체 기획은 [docs/GDD.md](docs/GDD.md) 참고.

## 실행 방법
1. [Godot 4.x](https://godotengine.org/download) 설치
2. Godot 실행 → "Import" → 이 저장소의 `project.godot` 선택
3. F5 또는 재생 버튼으로 실행

## 조작
- 이동: 방향키 또는 WASD
- 상호작용(밭갈기/심기/물주기/수확, NPC 대화): Space 또는 Enter
- 숫자키(1/2/3): 심을 씨앗 선택 (상점 UI가 열려 있을 때는 해당 씨앗 구매)
- 상점 UI가 열려 있을 때: X = 보유 작물 전부 판매, ESC = 상점 닫기
- 대화창이 열려 있을 때: ESC = 닫기 (다시 상호작용하면 다음 대사로 이어짐)
- K = 수동 저장, L = 수동 불러오기 (하루가 바뀔 때는 자동 저장됨)

## 현재 상태 (M3 — 마을 NPC/대화)
- 플레이어 이동, 농장 타일 갈기 → 심기 → 물주기 → 성장 → 수확 루프 (에셋 없이 색상 사각형으로 표현)
- 씨앗 3종(순무/감자/당근), 종류별 성장 시간·판매가 차등
- 골드 시스템 + 상점 NPC(씨앗 구매 / 작물 전체 판매)
- 스태미나 시스템: 밭일 행동마다 소모, 다 떨어지면 행동 불가, 하루가 바뀌면 회복
- 세이브/로드: `user://savegame.json`에 저장, 하루 전환 시 자동 저장 + K/L 수동 저장·불러오기
- 마을 NPC 2명(미나/테오) + 대화 시스템: 상호작용할 때마다 대사가 순서대로 이어짐
- HUD에 골드, 스태미나, 선택된 씨앗, 씨앗/작물 인벤토리 텍스트 표시

로드맵은 GDD의 9번 항목 참고.
